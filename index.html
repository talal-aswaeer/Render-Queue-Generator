GUI Render Queue Generator

Builds a render_queue_GUI.py to paste into Houdini's Python Source Editor. Runs on your normal interactive license — no hython, no hbatch — with per-scene frame ranges.

Setup

Progress is written here live — open it in Notepad while Houdini is frozen to check on the queue.

Render queue — rendered top to bottom

How to run it

  1. Open Houdini normally on the render PC (save any open work first!)
  2. Windows menu → Python Source Editor
  3. Paste the whole script, press Apply
  4. Houdini freezes while rendering — that's normal. Watch render_queue_log.txt or the output folders for progress. A summary dialog pops up when everything is done.

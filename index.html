GUI Render Queue Generator

Builds a render_queue_GUI.py to paste into Houdini's Python Source Editor. Runs on your normal interactive license — each ROP renders its own saved frame range.

Setup

Progress is written here live — open it in Notepad while Houdini is frozen to check on the queue.

Render queue — rendered top to bottom

How to run it

  1. Set the frame range you want on each scene's ROP, and save the hip file
  2. Open Houdini normally on the render PC (save any open work first!)
  3. Windows menu → Python Source Editor
  4. Paste the whole script, press Apply
  5. Houdini freezes while rendering — that's normal. Watch render_queue_log.txt or the output folders for progress. A summary dialog pops up when everything is done.
